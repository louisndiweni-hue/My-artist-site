# Louis Tee — website rebuild

This version is designed as a lightweight static Netlify site.

Changes:
- International artist positioning; no Zimbabwe location statement on the public page.
- Removed the long emotional descriptions.
- Removed duplicate SoundCloud/Linktree presentations.
- Direct buttons for SoundCloud, Audiomack, Instagram, SubmitHub and Linktree.
- Added a dedicated Instagram/latest-updates section for @louis_tee_music_original.
- Focused the homepage on Louis Tee as an artist.
- Kept the page lightweight and mobile-friendly.

Instagram note:
A static Netlify site cannot reliably scrape a public Instagram profile directly from browser JavaScript. The site therefore links directly to the profile instead of using a fragile scraper. If you later have an approved feed/API endpoint, the Updates section can be connected to it.

Identity:
The About Louis Tee section publicly displays the supplied full name and date of birth. Age is calculated in the browser from the birth date, so it updates automatically each year.


## Search / social identity
The public site now explicitly tells visitors how to find the artist:
- Instagram: @louis_tee_music_original
- Facebook Page: Louis Tee
- TikTok: @louis_tee_
- YouTube: @louis_tee_music

The social accounts are also linked in the footer and in the main "Find Louis Tee" section.


## Visuals
Four supplied Louis Tee images are included in the Visuals section and bundled locally for fast loading on Netlify.
